Tentang Saya

Halo, perkenalkan nama saya Radithya Javas Nararya yang biasa dipanggil Jage atau Javas. Minat saya sebetulnya lebih ke seni seperti musik dan fotografi, namun untuk akademik saya cenderung ke arah Teknik terutama Teknik Kimia.

Selama belajar TIK, kesabaran saya cukup diuji karena membuat website tidak mudah disebabkan banyak error-error kecil yang sering muncul dan sangat sulit ditemukan. Saya harap dengan belajar TIK saya bisa memanfaatkannya ketika saya kuliah ataupun kerja nanti.

Target Kompetensi & Capaian

Setelah menyelesaikan rangkaian pengerjaan project portofolio digital ini, saya diharapkan mampu memenuhi beberapa indikator kemampuan teknis, antara lain:

  • Struktur Data: Membuat struktur website menggunakan HTML.
  • Desain Antarmuka: Mendesain tampilan website menggunakan CSS.
  • Logika Dasar: Menggunakan JavaScript dasar pada website.
  • Manajemen Informasi: Menampilkan data diri dan informasi dalam bentuk website.
  • Sistem Navigasi: Membuat navigasi antar halaman website.
